AI customer support chatbot powered by your WordPress content without external AI services.

== Description ==

Syria Bot is a lightweight WordPress customer support chatbot that uses your website content to help visitors find information.

The plugin is designed to work without external AI services or third-party AI APIs.

== Features ==

* Customer support chatbot.
* Uses WordPress website content as its knowledge source.
* Works without external AI services.
* Automatic content search.
* Knowledge management from the WordPress dashboard.
* Custom bot name and welcome message.
* Frequently asked questions management.
* Lightweight frontend chatbot widget.
* RTL-friendly interface.
* Translation-ready.

== Installation ==

1. Upload the `syria-bot` folder to the `/wp-content/plugins/` directory.
2. Activate Syria Bot from the Plugins menu in WordPress.
3. Configure the plugin from the Syria Bot settings.
4. Add or manage the knowledge used by the chatbot.
5. The chatbot widget will appear on your website.

== Frequently Asked Questions ==

= Does Syria Bot require an external AI service? =

No. Syria Bot is designed to work using your WordPress content without external AI services.

= Does the plugin require an API key? =

No external AI API key is required.

= Can I customize the chatbot? =

Yes. The plugin provides settings for the bot name, welcome message, knowledge, and other chatbot options.

= Does it support Arabic websites? =

Yes. Syria Bot is designed with RTL and Arabic content in mind.
